# 1. Introduction
Giai đoạn 5 đánh dấu bước ngoặt biến BusZ từ một ứng dụng đặt vé truyền thống thành một Nền tảng Vận tải Thông minh tiên phong. Tích hợp AI là lợi thế bán hàng độc nhất (USP) so với các đối thủ trên thị trường.

---

# 2. Features Upgrade

## 2.1 AI Travel Assistant (NLP Booking)
Khung Chatbot xử lý ngôn ngữ tự nhiên:
- **Luồng xử lý:** Người dùng nhập: *"Tôi muốn đi Đà Lạt cuối tuần này"* -> AI phân tích ngữ nghĩa -> Gọi API tìm kiếm -> Trả về danh sách vé rẻ nhất.
- **Gợi ý tự động:** AI thông báo *"Xe ABC đang giảm 30%, khởi hành 21h. Bạn muốn đặt không?"*

## 2.2 AI Recommendation Engine
Cá nhân hóa màn hình Home (Personalization):
- Hệ thống Machine Learning học hành vi đặt vé trong quá khứ.
- **Đề xuất chủ động:** *"Bạn hay đi TPHCM -> Đà Lạt. Hôm nay có vé rẻ, đặt ngay!"*

## 2.3 AI Support & Customer Care
Trợ lý ảo hỗ trợ 24/7:
- Tự động hóa các luồng: Đổi vé, Hoàn vé.
- Giải đáp thắc mắc về chính sách hành lý, hủy vé của từng nhà xe cụ thể.
