# 13. User Journey

## 13.1 Luồng đặt vé chính

Home → Search → Trip Detail → Seat Selection → Passenger Information → Payment → Confirmation → My Bookings.

## 13.2 Mục tiêu UX theo bước

| Bước | Mục tiêu |
|---|---|
| Home | Bắt đầu tìm chuyến nhanh |
| Search | So sánh lựa chọn dễ dàng |
| Trip Detail | Tạo niềm tin trước khi mua |
| Seat | Chọn đúng ghế và hiểu giá |
| Passenger | Nhập dữ liệu không bị rối |
| Payment | Minh bạch, an toàn |
| Confirmation | Biết chắc giao dịch thành công |
| My Bookings | Dễ tìm lại vé và xử lý sau mua |

## 13.3 Điểm rơi bỏ cuộc cần theo dõi

- Không tìm thấy tuyến.
- Filter quá phức tạp.
- Không hiểu điểm đón/trả.
- Ghế vừa chọn bị mất.
- Form hành khách dài.
- Thanh toán thất bại.
- Không nhận được vé.
