# 14. Accessibility

## Yêu cầu

- Tương phản màu đạt WCAG AA.
- Điều hướng được bằng bàn phím.
- Focus state rõ ràng.
- Icon có aria-label khi không có text.
- Form có label thật, không chỉ placeholder.
- Thông báo lỗi được screen reader đọc.
- Seat map không phụ thuộc hoàn toàn vào màu.
- Hỗ trợ reduced motion.
- Font không nhỏ hơn 14px cho nội dung chính.
