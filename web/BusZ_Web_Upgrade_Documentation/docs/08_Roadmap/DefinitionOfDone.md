# 23. Definition of Done

Một hạng mục chỉ được xem là hoàn thành khi:

- Giao diện đúng design token.
- Hoạt động trên desktop và mobile.
- Có loading, empty, error state.
- TypeScript không có lỗi.
- Lint pass.
- Có test phù hợp.
- Không hardcode API URL hoặc secret.
- Không làm hỏng route và feature khác.
- Có acceptance criteria được kiểm tra.
- Tài liệu được cập nhật nếu thay đổi kiến trúc hoặc nghiệp vụ.
