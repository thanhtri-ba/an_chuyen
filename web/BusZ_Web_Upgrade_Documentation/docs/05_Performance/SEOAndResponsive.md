# 16. SEO và Responsive

## SEO

- Title và meta description theo route.
- Open Graph cho tuyến và ưu đãi.
- Structured data phù hợp.
- Sitemap và robots.txt.
- Canonical URL.
- Nội dung route phổ biến có thể index nếu phù hợp.

## Responsive

### Mobile

- Bottom navigation hoặc menu gọn.
- Filter dạng drawer/bottom sheet.
- CTA sticky.
- Card một cột.

### Tablet

- Grid hai cột phù hợp.
- Sidebar có thể thu gọn.

### Desktop

- Container 1200–1440px.
- Sidebar filter cố định.
- Tóm tắt đơn hàng sticky.
