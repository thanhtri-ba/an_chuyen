# 3. Nguyên tắc thiết kế

## 3.1 Định hướng

BusZ sử dụng phong cách hiện đại, thân thiện và đáng tin cậy. Giao diện cần tạo cảm giác dễ đặt vé, minh bạch về giá và an toàn khi thanh toán.

## 3.2 Nguyên tắc

1. **Rõ ràng trước đẹp mắt:** mọi thông tin quan trọng phải dễ đọc.
2. **Một hành động chính trên mỗi khu vực:** tránh nhiều nút cạnh tranh.
3. **Thông tin giá minh bạch:** luôn hiển thị giá cuối hoặc giải thích phí.
4. **Trạng thái có phản hồi:** click, loading, thành công, thất bại đều phải rõ.
5. **Mobile-first:** thiết kế từ màn hình nhỏ rồi mở rộng.
6. **Nhất quán:** cùng loại component phải có cùng hành vi.
