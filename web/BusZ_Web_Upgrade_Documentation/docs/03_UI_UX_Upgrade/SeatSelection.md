# 8. Nâng cấp chọn ghế

## 8.1 Trạng thái ghế

- Available.
- Selected.
- Occupied.
- Reserved.
- VIP.
- Female-only nếu nhà xe hỗ trợ.
- Disabled.

## 8.2 Tính năng

- Chọn nhiều ghế theo số hành khách.
- Hiển thị tầng 1/tầng 2.
- Chú thích rõ ràng.
- Gợi ý ghế gần nhau.
- Đồng bộ giá theo loại ghế.
- Countdown giữ ghế nếu backend hỗ trợ.

## 8.3 Xử lý lỗi

- Ghế vừa bị người khác giữ.
- Hết thời gian giữ ghế.
- Mất kết nối.
- Số ghế chọn vượt số hành khách.

## 8.4 Acceptance criteria

- Không cho chọn ghế không khả dụng.
- Tổng tiền cập nhật ngay.
- Có xác nhận trước khi bỏ toàn bộ ghế đã chọn.
- Trạng thái ghế có thể phân biệt ngoài màu sắc.
