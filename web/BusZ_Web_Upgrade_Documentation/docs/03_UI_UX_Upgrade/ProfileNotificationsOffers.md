# 12. Profile, Notifications và Offers

## 12.1 Profile

- Thông tin cá nhân.
- Hành khách đã lưu.
- Tuyến yêu thích.
- Phương thức thanh toán.
- Bảo mật và thiết bị.
- Ngôn ngữ.
- Cài đặt thông báo.

## 12.2 Notification center

Phân loại:

- Booking.
- Payment.
- Trip reminder.
- Promotion.
- System.
- Support.

Hỗ trợ đánh dấu đã đọc, lọc theo loại và deep-link đến màn hình liên quan.

## 12.3 Offers

- Danh sách voucher.
- Điều kiện áp dụng.
- Ngày hết hạn.
- Mã voucher.
- Nút áp dụng hoặc sao chép.
- Phân biệt voucher đủ điều kiện và chưa đủ điều kiện.
